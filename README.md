## hw-tracker

this is a simple homework tracker app built with HTML, CSS and JS wrapped using electron. It allows users to add, edit, and delete homework assignments, as well as mark them as completed.

the app is a desktop application that can be run on Windows and Linux.

### Features
- Add homework assignments with a title, description, and due date
- Delete homework assignments
- Mark homework assignments as completed
- View homework assignments in a list format

### Installation
1. Visit the official [releases page](https://hw-tracker.netlify.app/)
2. Download the latest version for your operating system (Windows or Linux)
3. Install the application by following the on-screen instructions

### Usage
1. Open the hw-tracker application
2. Use the input fields to add a new homework assignment
3. Click on the "Add" button to save the assignment
4. View your homework assignments in the list below
5. Click on the "Delete" button to remove an assignment
6. Click on the checkbox to mark an assignment as completed
